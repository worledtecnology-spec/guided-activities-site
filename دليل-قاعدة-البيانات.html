🔥 دليل ربط المنصة بقاعدة بيانات Firebase

قبل الربط تعمل المنصة في «وضع تجريبي»: كل شيء يعمل لكن البيانات تُحفظ على الجهاز نفسه فقط (للتجربة). بعد الربط تُحفظ كل البيانات في حسابك على Firebase، ويرى الطلاب تعليقات زملائهم من أي جهاز.

١) إنشاء المشروع

  1. ادخل console.firebase.google.com ← Add project ← اكتب اسمًا (مثل flipped-learning).
  2. من الصفحة الرئيسية للمشروع اضغط أيقونة الويب </> ← سجّل تطبيقًا ← سيظهر لك firebaseConfig.
  3. ✅ تم: بيانات مشروعك reading-a40c1 مضافة بالفعل في الموقعين.

٢) تفعيل الخدمات

  1. Authentication ← Get started ← Sign-in method ← فعّل Email/Password.
  2. Firestore Database ← Create database ← اختر Production mode ← المنطقة الأقرب (مثل europe-west).
  3. Storage ← Get started (لرفع صور وفيديوهات وتسجيلات الأنشطة الحرة). اختياري: يحتاج خطة Blaze. بدونه تُحفظ الملفات الصغيرة (حتى ٧٠٠ كيلوبايت) داخل قاعدة البيانات نفسها.

٣) حساب المشرف

  1. ✅ تم: حساب المشرف hind@gmail.com مضاف بالفعل في Authentication ومكتوب في الموقعين وملفات القواعد.
  2. هذا البريد مكتوب جاهزًا في الموقعين وفي ملفات القواعد، فلا تحتاج تعديل أي ملف. عند دخول المشرف يكفي كتابة admin وكلمة المرور.

٤) قواعد الأمان (مهم جدًا)

  1. Firestore ← Rules ← امسح الموجود والصق محتوى الملف firestore.rules ← Publish.
  2. Storage ← Rules ← الصق محتوى storage.rules ← Publish.

هذه القواعد تضمن: الطالب يرى بياناته فقط، والتعليقات يراها زملاء نفس المجموعة فقط (لا تداخل بين الحر والموجه)، والمشرف يرى كل شيء.

٥) إضافة الطلاب

  1. افتح admin.html من أي من الموقعين ← ادخل ببريد المشرف.
  2. تبويب «👥 الطلاب»: أضف الطالب (الاسم، اسم مستخدم إنجليزي، كلمة مرور ٦ أحرف+، الفصل، المجموعة: حرة أو موجهة)، أو الصق قائمة كاملة (كل سطر: الاسم، اسم المستخدم، كلمة المرور، الفصل).
  3. الطالب يدخل من زر «👤 دخول الطالب» باسم المستخدم وكلمة المرور. لو دخل من موقع المجموعة الأخرى ستظهر له رسالة توجهه لموقعه الصحيح.

٦) ماذا يُحفظ في قاعدة البيانات؟

  • users: حسابات الطلاب ومجموعاتهم.
  • progress: الخطوات التي أنجزها كل طالب في كل درس (يكمل من أي جهاز).
  • responses: كل الإجابات: التصويت، وقفات الفيديو، صندوق الفهم، الأنشطة (مع روابط الملفات)، تذكرة الخروج، التقويم والاختبار البعدي.
  • comments: نقاش الطلاب تحت كل فقرة (مع الردود).
  • highlights: تظليل كل طالب بالألوان الثلاثة.
  • harvest: «ثمرة قراءتي» لكل طالب في كل درس.
  • votes: تصويت التهيئة.

كل ذلك يظهر في لوحة المشرف مع زر «⬇️ تصدير CSV» يفتح في Excel.

٧) النشر على الإنترنت

ارفع مجلد كل موقع على أي استضافة (مثل Firebase Hosting أو Netlify أو GitHub Pages). ثم من Authentication ← Settings ← Authorized domains أضف نطاق الموقع.

ملحوظة: حذف حساب طالب نهائيًا يتم من Firebase Console ← Authentication. من لوحة المشرف يمكنك «إيقاف» الحساب فيُمنع من الدخول.
